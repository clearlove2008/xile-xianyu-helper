## 行为

商机挖掘增加“指定卖家”，输入数字用户 ID 或完整 goofish.com 主页地址。短链接需先打开后复制主页地址；例如本次用户提供的分享链接解析得到用户 ID 2222193158826。
GET /api/v1/opportunity/search 增加可选 seller 参数，与 keyword 至少提供一项；seller 优先。沿用登录鉴权、账号归属检查、MTOP 签名与账号节流。每页固定 20 条，最多 50 页，不自动刷新登录或循环重试。
只显示状态明确为在售的商品，排除重复及明确属于其他用户的卡片。分页按平台 nextPage 展示，totalCount 可能包含其他状态，不能当作当前可发布条数。

当前页商品可多选，支持统一价格（留空沿用各原价）、指定多个发布账号、原图或 AI 生图。列表展示摘要和主图；单品与批量发布前都会调用商品详情接口读取完整 desc 原文。保留换行、空行、缩进，不自动 AI 改写、不添加模板；详情缺失则停止。提供“读取完整原文预览”。多图与 SKU 未搬运。

点击批量按钮后还需确认商品数与账号数。串行发布、至少间隔 5 秒、异常立即停止；停止按钮只取消后续任务，当前请求不强制中断。
发布前 localStorage 写入 pending，成功后保存平台商品 ID；已有记录自动跳过。网络错误和缺少商品 ID 的响应保留待核对状态。只有用户核对平台后点击“解除所选待核对记录”才允许重试；成功记录不会删除。此保护仅在同一浏览器生效，不是跨设备幂等保证。页面关闭后队列不继续执行。

## 原文完整性修复
GET /api/v1/opportunity/detail 使用 item_id 和 cookie_id，沿用登录及账号归属校验。返回 itemId/title/description；description 直接取详情 itemDO.desc，不从列表 title 兜底。标题受平台 30 字限制，但不对正文执行限长、trim 或省略处理。真实发布仍需用户确认；平台自身的长度校验以错误提示为准，不静默截断。

预览、单件和批量上架在读取全文后统一转换已确认的平台表情占位码：`[右]` → ➡️、`[钉子]` → 📌、`[0]` 至 `[9]` → Unicode 键帽数字。标准表情、换行、空格和其他正文原样保留。未知方括号内容不批量删除，以免误删资料标签或普通正文；标准表情的图形样式可能因设备不同而不同。此处理只用于新读取的商机草稿，不自动修改已发布商品。
